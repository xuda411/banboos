# 财务模板参数口径扩展（2026-09-20）

本轮在服务器财务模型中加入模板中会直接影响现金流的参数，并保持旧任务的默认结果不变。原始 `独立储能项目经济性测算工具.xlsm` 仍只读保存，不被覆盖。

## 新增输入与计算

- 单边效率、DOD、年循环次数和循环寿命，用于记录服务器口径并支持模板式衰减方案。
- `eol_method=linear` 保留原服务器线性衰减；`calendar_cycle_min` 使用日历 EOL 与循环 EOL 的较小值。
- 土地租金、保险费率、固定运营费、其他运营费和收益分成门槛/比例纳入年度运营成本。
- 增值税、增值税附加和印花税纳入项目/资本金现金流；设备/其他投资进项税率、设备投资占比和抵扣比例驱动进项税余额结转，并在年度结果中单独列出销项税、实际应缴税、抵扣使用额、抵扣余额、附加、印花税、收益分成和保险费。
- 同时输出全投资/资本金税前 IRR、NPV 和年度税前现金流，便于与模板财务指标 D65/D78/D80 复核。
- 容量租赁、容量电费、补贴、一次/二次调频支持按运营年份分阶段启用、停止、EOL 衰减和年度增长，网页端以高级 JSON 规则提交，报表保留原始配置。
- 财务 XLSX 的“测算参数”“年度现金流”“财务指标”“模板映射”“公式复核”页同步显示这些字段。
- 新增“财务指标”横向工作表：按建设期（0 年）和运营年度展开收入、成本、税费、项目/资本金现金流、累计现金流，并用公式重算 IRR/NPV。
- 新增“财务模板”工作表：复现原始“财务指标”页的 0 年、运营年度、80 行指标顺序，金额统一换算为万元，关键行链接至服务器计算页，支持逐行人工核对。
- “财务模板”已按原表提取的视觉规则设置浅蓝表头、浅黄分组、分类纵向合并、紧凑列宽、冻结 D3 和关键 IRR 红色强调；原模板不参与写入。

当前仍明确保留的差异：模板原生宏、数据表、数组公式和部分 Excel/WPS 专有样式尚未完全复现。分阶段规则已展开到“阶段收益”工作表，并由公式复核页按年度引用重算。“财务指标”和“财务模板”属于可重算的服务器版模板排版层，暂不声称等同于原始 xlsm 的宏、命名区域或 Excel/WPS 专有样式。

## 验证

- 默认参数下原有财务单元测试全部通过，旧的无贷款/贷款手工现金流不变。
- 新增模板式参数测试覆盖保险、收益分成、增值税和日历/循环 EOL。
- 完整 XLSX 导出可生成新增年度字段；新模型公式复核页能生成包含新增口径的公式。
- 进项税余额可跨年度抵扣，抵扣耗尽后才产生实际应缴增值税；税前/税后指标同时导出。
- 全套测试和 Ruff 检查在提交前执行。
