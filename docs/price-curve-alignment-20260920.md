# 电价曲线对齐记录（2026-09-20）

对照版本：桌面版 Banboos 1.6.6 `gui/price_curve_panel.py` 与 `tests/test_price_interaction.py`。

## 本轮修正

| 桌面版行为 | 网页版修正 |
| --- | --- |
| 鼠标移动到 15 分钟点位显示节点、时间、电价和来源 | Canvas 现在按最近的 96 点定位，显示节点、日期、市场、点序号、时间、电价和来源模式 |
| 指向框在图表边缘保持在绘图区内 | DOM 指向框按画布边界夹紧，离开绘图区自动隐藏 |
| 单日电价使用低价红、中位黄、高价绿的渐变线 | 选中日期采用相同的三段式价格渐变；其它日期使用浅色对比线 |
| 纵轴有负电价空间，边界按 100 元对齐并限制在 -1000 至 3000 | 网页纵轴改为相同硬边界和刻度策略，负电价不会被压到零线以下不可读 |
| 当前曲线标题包含节点和日期 | 网页标题、统计摘要和指向框都保留节点、日期、市场上下文 |

## 尚未宣称完全等价的部分

网页版当前 API 仍以“单日 96 点曲线列表”为数据协议，支持多日叠加对比；桌面版还提供独立的月度平均和年度 12 个月/全年均值模式。月度、年度聚合及桌面版颜色条仍列入下一阶段功能对账，不会把多日叠加误标为月度统计。

- 页面显示均值、最低值、最高值和日期列表，Canvas 选中曲线按价格渐变绘制。
- 浏览器交互检查确认新增指向说明、节点/市场筛选和导出入口正常呈现。
