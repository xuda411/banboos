# 财务公式复核交付与验证（2026-09-17）

## 本次修复

原资本金现金流公式以收入减现金支出为起点，末尾又加回折旧，导致资本金现金流虚增。模型 `banboos-financial-1.0.1` 删除这次重复加回，所得税中的折旧扣除保持不变。无贷款条件下，资本金现金流与项目现金流应相等，新测试覆盖有换电池投资的情形。另以 200 万元投资、50% 贷款、两年期的手工算例，验证资本金现金流为 -100 万元、40 万元、45 万元。

模型版本随财务和敏感性任务输出保存。已完成的旧任务继续展示旧结果；重算须提交新任务，旧报告不改写。

## 导出变化

完整新任务导出增加“公式复核”页，从已有“测算参数”单元格重新计算 25 年或该任务经营期内的收入、运维、折旧、换电池、贷款利息、本金、余额、所得税及两类现金流。页末两列与服务器快照逐年对账，差额超过 0.01 元高亮。输入不完整或旧模型任务不生成此页。

复核页与结果快照明确区分：编辑参数后复核页重算，概览及其他明细仍保留原任务值。变更经营年限须在软件重新测算后导出。IRR、NPV 等概览数据继续是任务快照，不冒充随 Excel 输入变化的动态结果。文件请求 Excel 打开时全量重算。

模板映射补充了单边/往返效率、线性/日历及循环衰减、增值税、保险费、运营分成和税前/税后指标的真实差异。详见 [模板映射](financial-template-mapping.md)。原始模板未写入。
