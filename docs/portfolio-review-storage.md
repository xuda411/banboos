# 组合结果审批与存储适配

## 当前能力

- 组合结果可以按 `draft → pending → approved/rejected → archived` 流转。
- 每次流转记录操作者标识、备注、前后状态和 UTC 时间；接口使用 `expected_status` 可避免并发覆盖。
- `LocalObjectStore` 提供 `put/get/exists` 对象存储端口，当前 ZIP 归档落在 E 盘；路径和 key 均限制为单层文件名。
- Web 看板提供提交复核、批准、退回和标记已归档操作，状态变化后重新读取看板。

## 边界

操作者标识目前是联调审计字段，不等同于用户身份认证。跨租户共享、细粒度审批权限和对象存储生命周期策略需等 PostgreSQL 身份服务和 S3/OSS 适配完成后启用；当前不会把本地文件暴露为公开链接。
