# 财务模型自动复核

成功的财务任务现在支持 `GET /api/v1/runs/{run_id}/financial-reconciliation`。复核使用任务原始参数和结果快照，检查：

- 项目和资本金现金流长度、建设期首期现金流；
- 项目 NPV、资本金 NPV 与折现现金流重新计算值；
- 项目 IRR、资本金 IRR 与现金流重新计算值；
- 总投资与首期现金流；
- 每个运营年度的项目/资本金现金流与年度明细。

网页测算任务成功后可以点击“生成财务复核报告”。当前验证样本使用 `banboos-financial-1.3.1` 模型，通过 57 项检查；财务 XLSX 导出同时保留公式复核和重算复核页。
