# 边缘网关基础能力

`apps/edge/gateway.py` 提供本地 SQLite 遥测缓冲区，作为真实协议适配器接入前的稳定边界：

- 遥测点按 `raw_message_id` 去重，重复补传不会产生重复记录；
- 进程重启后仍可读取未确认批次；
- 未确认批次按事件时间回放，适配断网、乱序和批量补传；
- 云端确认后按 `batch_id` 标记完成；
- 心跳明确报告连接状态、待补传点数和 `control_mode=disabled`。
- 遥测上送时即时检查质量码、SOC 和温度，返回 `warning`/`critical` 结构化告警；告警只读，不自动下发控制。

当前模块只负责只读遥测上送准备，不接收或执行生产控制指令。真实 Modbus、IEC 104 或厂商协议适配器应在此边界之外实现，并保留原始报文和来源字段。
