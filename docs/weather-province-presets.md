# 省级气象预设与预计功率

当隔离数据库没有对应节点的气象观测时，气象接口会生成按省份区分的小时级展示序列，来源标记为 `省级预设·省份（展示数据）`，接口 `source_mode` 为 `province-preset`。真实观测存在时始终优先使用真实观测，不会用预设覆盖真实数据。

预设只用于客户展示和功率曲线联调，不作为真实气象、结算依据或生产控制输入。光伏预计功率按辐照度和温度修正，风电预计功率按风速曲线估算，两者在 `WeatherObservation` 中分别使用 `pv_predict_power_mw` 和 `wind_predict_power_mw`，并保留 `is_power_simulated=true`。

后续接入公开气象源或电站实测源时，只需写入标准气象观测表；同一接口会自动切换到真实来源，前端不需要改变。
