# Banboos 2.0 UI 专项迭代准备

## 当前基线

- 功能回归：`pytest` 105 项通过；代码规范检查通过。
- 浏览器联调：运营总览、组合筛选、真实节点候选生成和候选 Excel 导出已通过人工流程验证。
- 服务状态：开发环境 `staging-ready`；生产控制保持关闭；1.6.6 财务模板可用。
- 前端资源：脚本版本号已更新，避免浏览器继续使用旧版缓存资源。

## UI 迭代顺序

1. **信息架构与导航**：统一运营总览、节点分析、电价曲线、气象专题、约束回放、测算任务、组合筛选和系统管理的入口层级；保留当前功能语义，减少重复入口。
2. **数据密度与布局**：以 1440px、1280px 和窄屏为基准重排卡片、表格和图表，消除大面积留白；表格列提供固定宽度、横向滚动和长文本截断提示。
3. **交互状态**：统一加载、空数据、失败、只读、导出中和导出完成状态；所有导出按钮必须绑定最近一次成功加载条件，条件修改后自动失效。
4. **图表与指向信息**：统一曲线颜色、图例、悬浮提示和单位；节点、电价差、光伏/风电预计功率使用明确的系列颜色，并保证异常值有可读提示。
5. **财务输入与结果**：按“储能与寿命、运营与更换、融资与税费、容量收入、补贴与调频”分组；输入项、校验信息和结果摘要保持同一视觉规则。
6. **无障碍与可操作性**：补齐可见焦点、键盘顺序、表单标签、ARIA 状态播报和高对比度检查。
7. **视觉验收**：每个页面保留基准截图和关键流程清单，使用浏览器自动化复核导航、筛选、曲线查看、任务提交和 Excel/PNG 导出。

## 首轮验收标准

- 页面首次加载无脚本错误，API 状态与数据模式清晰可见。
- 任一筛选条件改变后，旧结果和旧导出按钮立即失效，不产生跨条件文件。
- 曲线系列颜色与图例一一对应，悬浮信息不遮挡主数据。
- 1280px 宽度下主要数据和操作仍可见，表格可横向滚动，右侧不出现无意义空白。
- 导出的 Excel 保留来源、条件、版本和模板对齐说明；导出的 PNG 包含标题、条件、来源和加载时间。

## 执行记录

### 2026-09-21 · 第一轮完成

- 总览、节点分析、电价曲线、气象专题完成密度与空状态调整。
- 财务测算增加参数分组计数、功率/容量时长提示和标准 2/4 小时制提示。
- 本地数据来源在界面中改为文件名摘要，避免暴露本机路径。
- 电价曲线和气象页面无数据时收起空白画布，加载数据后恢复完整图表。
- 浏览器人工检查覆盖财务参数分组切换、比例提示、财务任务提交和结果下载入口。

### 2026-09-22 · 系统管理页完成

- 系统健康、就绪、数据模式和生产控制统一为中文状态表达，隔离只读边界保持显式可见。
- 发布前门禁按“检查项 / 状态 / 说明”紧凑呈现，提示项与未通过项使用不同状态色，避免把可接受告警误读为故障。
- 最近任务审计增加任务类型中文映射、完成/失败/运行中状态徽标和滚动表体；筛选结果数量保持在标题旁即时反馈。
- 服务检查 JSON 限制展示高度，导入、门禁、审计表格减少无效留白，并保持窄屏横向滚动能力。
- 浏览器验证覆盖系统管理导航、门禁刷新、中文状态映射、任务列表和 staging-readonly 运行状态。
- 运营总览日报/月报增加可播报状态、空结果占位和来源摘要，报告条件返回有效结果时才保持 Excel 导出可用。

### 2026-09-22 · 图表指向信息完成

- 气象图表的四条系列保持固定颜色：辐照度金色、光伏预计功率橙色、风速青绿色、风电预计功率紫色。
- 气象图表新增指向提示，显示时间、辐照度、风速及两条预计功率；缺失值显示为“—”，不会跨缺口连线。
- 曲线指向增加竖向参考线，保持与电价曲线相同的定位反馈；功率继续明确标注为模型预计值。
- 浏览器验证覆盖气象数据加载、图例对应色、指向提示和预计功率数值展示。

### 2026-09-22 · 无障碍与可操作性完成

- 主导航补齐 `aria-controls` 与 `aria-current`，切换页面时当前入口同步更新，便于键盘和辅助技术识别位置。
- 电价与气象图表增加可聚焦语义、描述文本和动态指向状态；图表仍保留鼠标提示，不改变原有导出流程。
- 统一焦点可见样式，避免键盘操作时无法定位当前控件。
- 浏览器验证覆盖导航当前项、曲线加载后的图表可访问名称和气象页面的动态状态结构。
- 修正运营总览“质量与气象”快捷入口，使其直接进入气象专题；增加 `prefers-reduced-motion` 适配，减少动态效果对操作的干扰。
- 响应式验收补齐 560px 以下规则：财务完整参数、敏感性分析和节点分析表单改为单列，运营与导入工具栏控件允许稳定换行，降低小屏横向溢出风险。

### 2026-09-22 · 财务结果交付区完成

- 财务测算完成后将交付文件、核心结果和复核动作分成三层，用户可直接定位 XLSX、XLSM、财务复核和 1.6.6 模板复核入口。
- 核心结果增加“项目财务摘要”标题和完成状态，四项指标保留单位、数值对齐和窄屏换行规则。
- 浏览器验证覆盖真实财务任务完成、结果摘要显示、两个下载入口和两类复核按钮。

### 2026-09-22 · 任务交互状态完成

- 财务测算、约束回放、组合优化和敏感性分析提交期间统一禁用主操作，并通过 `aria-busy` 暴露忙碌状态，完成或失败后自动恢复。
- 价差分析、投资情景、候选生成及快照优化沿用同一忙碌反馈，避免重复提交和用户误以为页面无响应。
- 任务轮询统一显示“排队中 / 执行中 / 已完成 / 失败 / 已取消”和百分比，系统管理页的任务审计使用同一状态词和颜色。
- 组合优化轮询期间同步更新状态徽标，失败与取消改用错误色，避免把失败任务误读为仍在运行。
- 浏览器验证覆盖财务提交按钮忙碌状态、完成后的结果恢复、状态中文化和系统任务列表一致性。

### 2026-09-22 · 登录与权限界面准备完成

- 顶部增加会话状态和登录入口，令牌只保存在当前浏览器会话；API 返回 401 时自动打开登录提示。
- 系统管理增加“用户权限管理”卡片，按平台管理员、运营分析员、财务分析员和审计只读展示权限矩阵与租户范围。
- 新增版本化 `/api/v1/auth/session` 与 `/api/v1/auth/policy` 契约，当前以 API token / 开发联调会话驱动，权限写入仍保持预览模式。
- Excel 导出请求沿用当前会话令牌，避免上线启用认证后导出链路失效。
- 明确生产上线前必须接入 PostgreSQL 用户、租户、角色和审计持久化，不能把当前策略预览误认为正式账号系统。
- 浏览器验证覆盖会话状态、登录弹窗、角色切换和 9 项权限卡片渲染。
- 登录弹窗完成 Banboos 专属能源控制室视觉改版：左侧展示节点、电价、气象和财务能力摘要，右侧聚焦令牌接入；保留会话存储、错误播报和关闭交互。
- 登录入口已切换为手机号 / 邮箱 / 微信方式预览，验证码发送状态由 `/api/v1/auth/methods` 返回；API token 收纳为开发联调 fallback，不再作为正式用户登录主入口。

### 2026-09-22 · 服务状态可读化

- 就绪检查不再把原始 JSON 直接展示给用户，`api`、`redis`、`auth` 转为中文服务清单。
- `not-configured` 显示为“未配置（本地开发模式）”，与“不可用”区分，避免把开发环境提示误读成乱码或故障。
- 保留 `/readyz` 原始 JSON 契约给程序和日志使用，页面只负责面向用户的可读呈现。

### 2026-09-22 · 财务输入行对齐

- 财务测算首行输入改为顶部统一对齐，容量/功率比例提示固定在容量字段下方，不再把其他字段和提交按钮向上或向下挤压。
- 桌面宽度保持“标签 → 输入 → 提示”的稳定节奏，小屏仍按单列排列并取消按钮额外上边距。
- 组合筛选的市场、日期、功率和容量筛选项改为同一行网格，避免容量字段和“比较候选节点”按钮落到第二行。
- 电价曲线悬浮提示改为自适应换行并限制最大宽度，长节点名、来源和时间信息在窄窗口下保持可读，不遮挡曲线。

### 2026-09-22 · 再生能源品牌视觉深化

- 总览首屏增加“可再生、数据可追溯、服务新能源”价值表达，运营口号与产品真实能力保持一致。
- 新增生成式水墨竹林品牌素材，保留竹节、弯曲枝干和新生竹叶，作为总览首屏与登录页的克制背景材质。
- 顶部品牌标识补充“新能源运营”副标题；数据卡片继续使用高可读的纸面底色，品牌画面不进入表格和图表内容层。
- 水墨素材位于装饰层，登录遮罩、键盘焦点和数据操作不受影响；窄屏自动降低画面强度。
