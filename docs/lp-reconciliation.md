# LP 逐字段对账

完成的 `lp-analysis` 任务现在支持 `GET /api/v1/runs/{run_id}/reconciliation`。接口只接受成功的 LP 回放任务，并对同一输入快照执行纯只读检查：

- 每个历史日的价格、充电、放电、SOC 轨迹均为 96 点且为有限数；
- SOC 在允许的归一化范围内，充放电没有同时运行；
- 日净收益与求解器的收入、充电成本、门槛成本和衰减成本逐日复核；损耗、输电和交叉补贴已包含在充放电价格中，不重复扣除；
- 总净收益与逐日合计一致；
- 月度、年度净收益合计与逐日结果一致。

网页“约束回放”切换到 LP 详细回放并成功后，可点击“生成 LP 对账报告”。对账通过会显示检查项数量、失败数量和算法版本；发现差异时保留失败项及实际/期望值，便于定位模型口径问题。

该报告是历史回放的业务验收工具，不代表生产调度执行或现场设备回执。
