# 真实节点组合候选

组合筛选页新增“从真实节点生成候选”。接口 `GET /api/v1/portfolio/candidates` 读取当前隔离 staging 数据，对每个节点分别计算指定市场、日期范围和储能时长的年度窗口价差，并生成：

- 节点名称、省份、市场和来源模式；
- 功率、容量、时长和单位投资；
- 有效日数、年度价差和年化净现金流（万元）。

每次真实数据生成都会写入内容寻址候选快照并返回 `snapshot_id` 与算法版本；演示模式返回空候选和 `demo` 标识，不写入快照。

候选项目仍需人工确认投资、预算和收益目标后，才提交组合优化任务。日前和实时不会混合，缺少完整有效曲线的节点不会生成候选。当前默认规模为 100 MW / 200 MWh，可在页面调整，功率与容量只校验时长关系，不锁死规模。
