# Banboos 1.6.6 / 2.0 全功能对比测试报告

测试日期：2026-09-15。测试对象为冻结的桌面版 1.6.6 和 `E:\Banboos2.0` 当前提交；桌面源代码、数据库及原始 xlsm 均未修改。

## 测试结论

桌面版 1.6.6 自动化测试 **125 passed、26 warnings、36 subtests passed**；Banboos 2.0 自动化测试 **44 passed、2 warnings**。1.6.6 测试在 E 盘专用 `.desktop-review-venv` 中执行，测试源代码目录保持只读。2.0 全量测试在 `E:\Banboos2.0\.venv` 中执行。

桌面版另完成 `core`、`analysis`、`database`、`quality`、`services`、`utils` 静态编译检查，结果通过。冻结桌面包的原生 Windows 人工检查结果为 **20/20 checks true，exit=0，DPR=1.5**，覆盖导航、幂等、冲突保留、调度成功、严格互斥、旧结果禁用、财务成功和窗口关闭流程。

2.0 Web 逐页人工检查覆盖运营总览、节点分析、电价曲线、气象专题、约束回放、测算任务、组合筛选和系统管理；API 状态为 `ok`，`/readyz` 为 `ready`，浏览器控制台无错误。Demo 模式的电价和气象有效数据为 0，页面正确显示空结果并禁用相应导出，未用模拟值冒充真实数据。

## 发现与风险

1. 桌面版 1.6.6 的 125 项测试已通过；26 个警告主要来自依赖库弃用提示及 openpyxl 对旧 xlsm 扩展的兼容提示，不是业务断言失败。
2. 2.0 当前使用 demo 模式启动。真实节点、电价和气象数据需配置 `BANBOOS2_LEGACY_DB` 的隔离副本后，才能进行逐日期、逐金额的 1.6.6 数值对账。
3. 组合筛选页面目前是数据覆盖率预筛选，不等同于桌面 LP 组合优化；该差异已保留在路线图中。
4. 当前服务器 Excel 是结构化可追溯输出，已增加模板映射清单；与用户 xlsm 的原生单元格、公式和样式逐项一致性尚未宣称完成。
5. 导出接口在空数据时返回明确错误，前端禁用按钮，避免生成没有事实依据的空报告。

## 上线判定

当前可作为 **Web/API 联调和人工验收版本**，不应判定为完全替代 1.6.6 的生产财务工具。进入预发布前必须完成：隔离真实数据数值对账、LP 组合优化迁移、xlsm 逐单元格公式/样式对账、省级气象预设和导入审计流程。生产控制仍保持关闭，符合 2.0 开发宪法。
