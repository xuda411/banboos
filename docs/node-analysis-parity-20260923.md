# 节点分析 1.6.6 对齐说明

网页版节点分析现在同时计算两组固定储能窗口：2 小时对应连续 8 个 15 分钟点，4 小时对应连续 16 个 15 分钟点。每条完整 96 点曲线遍历全部连续窗口，分别取窗口算术均价的最低值和最高值；同一有效日内先得到价差，再按有效日等权汇总到月度和年度基准。缺失或非有限点的曲线不参与计算，重复来源日按去重后的有效曲线处理。

功率与容量仍决定项目联动的时长（`容量 ÷ 功率`）。100 MW / 200 MWh 使用 2 小时基准，50 MW / 200 MWh 使用 4 小时基准；用户输入其他 15 分钟整数时长时，系统保留该项目时长，同时仍展示 2 小时和 4 小时对照结果。

节点分析任务 Excel 现在包含：

- `任务参数` 与 `结果摘要`；
- `月度价差`，并列输出 2 小时、4 小时和项目时长价差；
- `年度基准`，记录有效日、日期范围、低/高窗口均价、价差和数据质量计数；
- `滑动窗口口径`，明确 8 点和 16 点算法。

该口径用于历史投资基准和财务联动，不代表真实调度成交结果；需要执行约束、SOC、效率和终态约束时，应使用严格调度或 LP 回放。
