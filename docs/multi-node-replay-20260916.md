## 财务验证口径

回放使用同一服务器财务模型 `banboos-financial-1.0.0`，分别代入源快照与迁移库年度基准，比较完整结果（逐年现金流、全投资/资本金 IRR、NPV、回收期等）。比较不是独立桌面模型验证。

本次明确假设：容量 200MWh，2h 为 100MW、4h 为 50MW，往返效率 92%，365 次/年，单位投资 1.2 元/Wh，运营期 25 年；其余参数逐项保存在 JSON 的 `inputs` 中。测试另覆盖 120MWh 的 60MW/30MW 配比，业务规模不锁定。收益为历史充放电均价构造的投资情景，不是实际运营收入。

日期抽样、缺失年度基准、非有限价格、空回放不能判定通过。单批失败记录错误并继续独立节点；报告每批原子保存；重跑复用已成功范围；报告路径不能覆盖源库、快照、清单或迁移库。
