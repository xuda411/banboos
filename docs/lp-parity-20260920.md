# LP 详细回放迭代记录（2026-09-20）

本次迭代把桌面版 1.6.6 的 LP 分析主链路接入 Banboos 2.0 的异步任务体系，任务名为 `lp-analysis`。原有 `strict-dispatch` 任务保持兼容，两个任务都只读取经过迁移的只读数据，不执行电站控制。

## 已对齐内容

- 96 点严格互斥 MILP、SOC 守恒、日末 SOC 复位、循环上限、效率、门槛收益和成本项沿用统一领域求解器。
- 逐日结果保留电价、充电功率、放电功率、区间末 SOC、充放电成本、放电收入、门槛成本、衰减成本、净收益、循环次数、价差和求解间隙。
- 按桌面版口径生成月度和年度汇总。
- 生成连续窗口套利基准对比；LP 结果、基准结果和提升比例逐日可追溯。
- 可选 C 率敏感性（默认关闭，单次最多 8 个 C 率），使用同一历史曲线和同一严格求解规则。
- 任务参数、算法版本和完整历史电价输入写入内容寻址快照；XLSX 导出包含任务参数、摘要、逐日结果、96 点轨迹、月度/年度汇总、基准对比和敏感性（若请求）。
- Web“约束回放”增加“LP 详细回放（对齐 1.6.6）”模式和月度结果展示，审计任务筛选也支持该任务类型。
