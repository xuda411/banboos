# 组合优化验证记录（2026-09-16）

本轮针对 1.6.6 `PortfolioOptimizer` 的 Web/API 对齐进行了验证：

- 三种目标与桌面端语义一致：最大 NPV、最大 IRR、收益目标下最小投资。
- 投资公式为 `容量（MWh）×单位投资（元/Wh）×100`，运营期年净现金流按年金折现。
- 组合允许 1–50 个候选项目，采用整数优化完整评估；不会静默丢弃第 21 个及之后的项目。
- 最大 NPV 不选择 NPV≤0 的项目；无可选和约束无解均有独立结果状态。
- Web 支持手工项目表格、输入校验、异步任务、恢复上次任务和 Excel 结果导出。

验证结果：60 个 Web/API/领域测试通过；浏览器手工录入 10 MWh、1 元/Wh、300 万元年净现金流、1000 万元预算，页面返回投资 1000.00 万元、NPV 1567.84 万元、组合 IRR 29.37%，并显示 Excel 下载按钮。

限制：当前项目收益为手工年净现金流假设，未自动从逐年财务任务导入；接入真实项目现金流前，结果必须继续保持“手工情景”标识。
